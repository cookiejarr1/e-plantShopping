## Project Overview
**e-plantShopping** is a dedicated e-commerce solution for plant enthusiasts. The application focuses on providing a high-fidelity user interface and a smooth shopping experience, allowing users to explore various plant categories, view detailed care instructions, and manage their digital garden cart with ease.

### Key Features

*   **Curated Catalog:** Browse a wide variety of plants categorized by environment and care level.
    
*   **Responsive Design:** Fully optimized for desktop, tablet, and mobile viewing.
    
*   **Interactive Shopping Cart:** Real-time updates for adding, removing, or adjusting plant quantities.
    
*   **Intuitive UI/UX:** Clean, nature-inspired aesthetics to match the product vibe.
    

### Tech Stack
This project leverages modern web technologies to ensure performance and scalability:

*   **Frontend:** React 
    
*   **Styling:** CSS
    
*   **State Management:** Redux Toolkit
